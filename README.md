# West Cosmic Youtube Music Theme

Cosmic Theme for desktop interface of **YouTube Music**.

## 🚀 Como Instalar

1. First, make sure you have the **Stylus** extension installed in your browser:
   - [Stylus for Chrome/Edge/Brave](https://chromewebstore.google.com/detail/stylus/clngdbkpkpeebahjckkjfobafhncgmne)
   - [Stylus para Firefox](https://addons.mozilla.org/pt-BR/firefox/addon/styl-us/)
2. With the extension installed, click the link below to install the theme automatically:
   - 👉 **[Install YTMusic Cosmic Theme](https://raw.githubusercontent.com/wesleycosme/west_ytmusic_themes/refs/heads/main/West_Cosmic_YTMusic_Theme_V1_user.css)**
